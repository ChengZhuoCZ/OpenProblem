# Problem 055 - Quasi-Complemented Separable Subspaces

A subspace \(M\subseteq X\) is quasi-complemented if there is \(N\subseteq X\) with

\[
M\cap N=\{0\},\qquad M+N=X.
\]

Does every infinite-dimensional Banach space have a quasi-complemented, separable, infinite-dimensional subspace?
