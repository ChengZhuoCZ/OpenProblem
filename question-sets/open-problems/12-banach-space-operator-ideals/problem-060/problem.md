# Problem 060 - Operators of Fourier Type \(2\)

An operator \(T:X\to Y\) has Fourier type \(2\) if some \(c_0\ge0\) satisfies

\[
\left(\frac1n\sum_{h=1}^n\left\|\sum_{k=1}^n e^{2\pi i hk/n}Tx_k\right\|_Y^2\right)^{1/2}
\le c_0\left(\sum_{k=1}^n\|x_k\|_X^2\right)^{1/2}
\]

for all \(n\) and \(x_1,\ldots,x_n\in X\). Must every such \(T\) factor through a Hilbert space, i.e. \(T=BA\) for bounded \(A:X\to H\) and \(B:H\to Y\)?
