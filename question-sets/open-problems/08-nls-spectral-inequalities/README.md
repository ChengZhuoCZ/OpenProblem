# Nonlinear Schrödinger Equations and Spectral Inequalities

Open problems involving nonlinear Schrödinger variational systems, orthonormal
families, binding inequalities, and their connections with sharp spectral
inequalities.

This category currently contains `problem-039`. Each problem has:

- `problem.md`: a maintained statement of the open problem.
- `progress.md`: current status, known partial results, and next actions.
