# Problem 064 - Tail-Space Total-Influence Strengthening

Let \(f:\{-1,1\}^n\to\{0,1\}\), and suppose \(k=k(n)\to\infty\). Does there exist \(\omega(k)\to\infty\) such that, whenever

\[
\mathbb EfW_S=0\qquad\text{for every }S\subseteq[n]\text{ with }1\le |S|\le k,
\]

then

\[
\sum_{i=1}^n I_i(f)
\ge \omega(k)(\mathbb Ef)\log\left(\frac1{\mathbb Ef}\right)?
\]
