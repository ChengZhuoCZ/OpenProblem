# Problem 043 - Optimal Scalar Constant in a Riesz Estimate from Below

Let \(\{-1,1\}^n\) be the discrete cube. For \(j\in[n]\), set

\[
D_jf(\varepsilon)=\frac{f(\varepsilon)-f(\varepsilon^{\oplus j})}{2},
\qquad
\Delta f=-\sum_{j=1}^nD_jf.
\]

If \(\delta=(\delta_1,\ldots,\delta_n)\) is an independent Rademacher vector and \(2\le p<\infty\), one has an estimate of the form

\[
\left\|\sum_{i=1}^n\Delta^{-1/2}D_if\right\|_p
\le Cp^{3/2}\left(\mathbb E_\delta\left\|\sum_{i=1}^n\delta_iD_if\right\|_p^p\right)^{1/p}.
\]

Can the factor \(Cp^{3/2}\) be improved to order \(Cp\), with constants independent of \(n\)?
