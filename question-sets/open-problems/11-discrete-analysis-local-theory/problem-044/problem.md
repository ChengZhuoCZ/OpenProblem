# Problem 044 - A Scalar Riesz Estimate from Above for \(1<p<2\)

For a scalar function \(f\) on \(\{-1,1\}^n\), define

\[
|\nabla f|_{\ell_2}=\left(\sum_{i=1}^n|D_if|^2\right)^{1/2}.
\]

For \(1<p<2\), is there a constant independent of \(n\) such that

\[
\big\||\nabla f|_{\ell_2}\big\|_p\lesssim\|\Delta^{1/p}f\|_p?
\]
