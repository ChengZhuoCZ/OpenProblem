# Ginzburg-Landau Problems from Brezis

Problems imported from Haim Brezis, "Some of My Favorite Open Problems", Open Problems 2.1-2.4.

Primary source: https://ems.press/journals/rlm/articles/13272471

This category stores problems `problem-035` through `problem-038`. Each problem has:

- `problem.md`: a maintained statement of the open problem.
- `progress.md`: current status, known partial results, and next actions.
